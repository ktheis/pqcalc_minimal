This is code for an online calculator described here: https://doi.org/10.1021/acs.jchemed.5b00366

It is the current version, stripped off the additional functionality described here: https://doi.org/10.1515/cti-2018-0009. With the advances in artificial intelligence, there no longer seems a need for a pseudo-intelligent tutor. At the same time, I am looking to offer the core calculator on different platforms, and wanted to preserve this state for further development (or change in language).

The repository now also contains a javascript implementation, created with Gemini 3.8 Flash high and Antigravity. Files include index.html plus the folders js, css, assets and tests. The underlying engine works to the same specifications as the python program, but the user interface has more buttons and thus less space for the output.
